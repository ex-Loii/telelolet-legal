# Telelolet — dokumen resmi

Halaman Kebijakan Privasi dan Ketentuan Layanan aplikasi **Telelolet** untuk Android
(`app.telelolet`), diterbitkan lewat GitHub Pages.

- Kebijakan Privasi: <https://ex-loii.github.io/telelolet-legal/privacy.html>
- Ketentuan Layanan: <https://ex-loii.github.io/telelolet-legal/terms.html>

Sumber aslinya ada di folder `legal/` pada repo aplikasi. Bila diubah di sana,
salin lagi ke sini supaya kedua tempat tidak berbeda isi.

GitHub Pages menyajikan isi branch **`gh-pages`**, bukan `main`. Kedua branch
sengaja dijaga sama isinya, jadi setiap perubahan harus dikirim ke dua-duanya.

Telelolet bukan aplikasi resmi Telegram dan tidak berafiliasi dengan
Telegram Messenger LLP.
